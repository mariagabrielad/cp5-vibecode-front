# 02 — Prompts e interações com IA

## Briefing original
“Crie uma landing page para um website. Use cores discretas como #4A5D4E para mesclar com o #F8F9FA e transformar em um visual limpo e minimalista, #2D3142 para textos e #D97450 para botões. Use referências sofisticadas, minimalistas e elegante. Como banners use as duas primeiras imagens anexadas e as três últimas como um carrossel de referências de livro que ao clicar nas fotos tenha textos explicativos/sinopses referente aos livros das fotos. Em todas as imagens, você pode usar um bloco genérico, para que eu possa alterá-las posteriormente, mas crie toda a estrutura para mim.”

## Como o briefing foi interpretado
- As duas primeiras imagens foram destinadas às áreas de banner e apresentação.
- As três últimas imagens foram usadas nos cartões de livros.
- Cada cartão abre um modal com sinopse e pergunta para discussão.
- A paleta indicada foi aplicada às cores principais.
- As imagens foram separadas em `assets` para facilitar a substituição.
- O layout foi pensado para telas grandes e pequenas.
