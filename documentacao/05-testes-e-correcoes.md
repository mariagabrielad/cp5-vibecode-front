# 05 — Testes e correções

## Checklist
- [ ] Abrir `index.html` no navegador.
- [ ] Confirmar que as cinco imagens aparecem.
- [ ] Testar os links da navegação.
- [ ] Clicar nos três livros e verificar sinopse e título.
- [ ] Fechar o modal pelo botão.
- [ ] Fechar o modal clicando fora.
- [ ] Fechar o modal usando Escape.
- [ ] Testar as setas do carrossel.
- [ ] Testar a página em largura de celular.
- [ ] Verificar se não há rolagem horizontal indesejada na página inteira.
- [ ] Testar o botão “Tenho interesse”.

## Limitações conhecidas
- O botão “Tenho interesse” é demonstrativo e não envia inscrição.
- As sinopses são textos introdutórios para apresentar as obras.
- As fontes externas dependem de conexão com a internet.
- Para trocar imagens, manter os nomes atuais ou atualizar os caminhos no HTML e JavaScript.

## Registro de avaliação crítica
Depois de testar, anote problemas reais encontrados, mudanças feitas e o resultado. Se usar IA para corrigir, registre o prompt exato, o que a IA entregou e como você verificou a solução. Não marque um teste como concluído antes de realizá-lo.
