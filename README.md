# Entrelinhas — Clube do Livro

Landing page responsiva desenvolvida a partir do briefing do trabalho de vibecode.

## Como abrir
1. Extraia a pasta do projeto.
2. Abra a pasta `entrelinhas-vibecode` no VS Code.
3. Abra `index.html` no navegador. Também pode usar Live Server.
4. Mantenha a pasta `assets` junto do arquivo HTML.

## Estrutura
- `index.html`: HTML, CSS e JavaScript da página.
- `assets/`: cinco imagens fornecidas como referências.
- `documentacao/`: objetivo, prompts, referências, identidade visual e testes.

## Interações
- Navegação por seções.
- Carrossel horizontal de livros com setas.
- Modal com sinopse e pergunta de discussão ao clicar em cada livro.
- Botão demonstrativo de interesse.

## Personalização
As imagens ficam na pasta `assets`. Para substituí-las, mantenha os nomes dos arquivos ou atualize os caminhos no HTML e no JavaScript.

O botão de interesse é apenas demonstrativo e não envia dados.
